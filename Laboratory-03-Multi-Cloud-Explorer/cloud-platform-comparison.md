# Cloud Platform Comparison

## AWS vs. Microsoft Azure vs. Google Cloud Platform

The following table compares several important characteristics and core services offered by Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| **Launch Year** | 2006 | 2010 | 2008 (App Engine, an early GCP service) |
| **Compute Service** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage Service** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking Service** | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| **Identity Service** | AWS IAM | Microsoft Entra ID | Cloud IAM |
| **Primary Strength** | Broad service portfolio and flexible infrastructure | Microsoft ecosystem and hybrid enterprise integration | AI/ML, data analytics, and Kubernetes/cloud-native technologies |
| **Ideal Organizations** | Startups, enterprises, global applications, and organizations requiring a broad range of cloud services | Microsoft-centered enterprises, schools, government organizations, and hybrid environments | AI/ML companies, research organizations, data-intensive businesses, and cloud-native development teams |

# Analysis Questions

## 1. Which cloud provider offers the broadest range of services?

For this comparison, I would identify **Amazon Web Services (AWS)** as the provider with the broadest range of cloud services. AWS has an extensive portfolio covering infrastructure, storage, databases, networking, analytics, artificial intelligence, serverless computing, security, application development, Internet of Things, and many other workloads.

## 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** is the strongest choice for organizations that already depend heavily on Microsoft technologies. Azure works closely with services and products such as Windows Server, Microsoft Entra ID, Microsoft 365, SQL technologies, and Microsoft's broader enterprise ecosystem.

## 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

For AI and Kubernetes-focused workloads, I would select **Google Cloud Platform**. Google Cloud provides Vertex AI for machine-learning and AI development and Google Kubernetes Engine (GKE) for managed Kubernetes, while Kubernetes itself originated from technology developed at Google before being released as an open-source project.

## 4. Which cloud platform would you personally choose and why?

I would personally choose **AWS** for a general-purpose cloud environment because of its broad selection of services and the flexibility it provides for many different workload types. Its combination of virtual machines, storage, networking, databases, serverless computing, containers, and global infrastructure would allow me to experiment with many different cloud architectures using one platform.

# Equivalent Cloud Services

The three cloud providers frequently provide comparable capabilities under different product names. The table below matches several commonly used services.

| Service Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| **Virtual Machine** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Object Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Identity Management** | AWS Identity and Access Management (IAM) | Microsoft Entra ID | Cloud Identity and Access Management (IAM) |
| **SQL Database** | Amazon RDS | Azure SQL Database | Cloud SQL |
| **Kubernetes** | Amazon Elastic Kubernetes Service (EKS) | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## Service Mapping Notes

### Virtual Machines

Amazon EC2, Azure Virtual Machines, and Google Compute Engine provide virtual computing resources that can host operating systems and applications in the cloud.

### Object Storage

Amazon S3, Azure Blob Storage, and Google Cloud Storage provide object-storage capabilities for files, application objects, backups, media, archives, logs, and other unstructured data.

### Identity Management

AWS IAM, Microsoft Entra ID, and Google Cloud IAM provide identity and access-control capabilities, although their specific architectures, terminology, and integration features differ.

### SQL Databases

Amazon RDS, Azure SQL Database, and Google Cloud SQL provide managed relational database capabilities.

### Kubernetes

Amazon EKS, Azure Kubernetes Service, and Google Kubernetes Engine provide managed environments for running Kubernetes workloads.
